# Zotero Quick Read Note 使用说明

[English](USAGE.en.md) · [项目主页](../README.md)

## 安装

1. 下载 [GitHub Releases](https://github.com/Hzx0211/Zotero-Quick-Read-Note/releases/latest) 中的 `zotero-quick-read-note.xpi`。请下载 XPI 文件，不要下载 GitHub 自动生成的源码压缩包。
2. 打开 Zotero 10，进入 **工具 → 插件**，把 XPI 文件拖进插件窗口，按提示安装。
3. 如设置页没有立即出现，重启 Zotero。以后更新时，安装新版 XPI 即可。

## 配置

在 Zotero **设置**侧栏打开 **Zotero Quick Read Note**：

| 字段                   | 如何填写                                                                                                                                                                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API 服务商             | 选择 OpenAI、火山方舟、DeepSeek、智谱、Kimi、通义千问、Claude、Gemini 或自定义。每家单独保存地址、Key 和 Model。                                                                                                                              |
| API 协议               | 仅自定义服务商可选：OpenAI 兼容、Claude Messages 或 Gemini GenerateContent。                                                                                                                                                                  |
| API 地址               | 预设会填入推荐地址，也可修改。OpenAI 兼容协议既接受 Base URL（如火山方舟 `https://ark.cn-beijing.volces.com/api/v3`），也接受完整的 `/chat/completions` 地址，不会重复追加。远程地址须为 HTTPS；本机 `localhost` 或 `127.0.0.1` 可使用 HTTP。 |
| API Key                | 当前服务商提供的密钥。                                                                                                                                                                                                                        |
| Model                  | 当前服务商支持的模型名称或接入点 ID，按其文档填写。                                                                                                                                                                                           |
| Analysis Prompt        | 对模型的分析要求，例如事实来源、写作风格和输出语言。默认收起，点击“展开并自定义”可修改。                                                                                                                                                      |
| Research Context       | 你的研究方向，可手动填写，也可从文件推断；推断结果预览后点击“应用”才会覆盖原内容。                                                                                                                                                            |
| Markdown Note Template | 你希望笔记遵循的完整 Markdown 模板，可增删标题或调整层级。                                                                                                                                                                                    |
| Note Style             | Cards（默认）把 Markdown 一级标题及其正文显示为信息卡片；Classic 保持标准 Markdown 富文本样式；Flow & Tables（流程图）在适合的章节生成可编辑的流程和表格。                                                                                    |

修改字段后离开该输入框，设置即保存在本机 Zotero 配置中。升级前填写的地址、Key 和 Model 保留在“自定义”服务商中。API Key 以本机 preference 明文保存，不会写入笔记；生成时，文献元数据、摘要及可用的 PDF 文本会发送到你配置的 API 地址。请使用你信任的服务商。

点击 **测试连接** 会发送一条简短的真实请求，检查地址、Key 和 Model；不会创建笔记，但可能产生少量费用。火山方舟建议先选择预设，填写 API Key 和模型 ID，再测试。

点击 **从文件推断研究领域** 可一次选择最多 5 份 PDF、DOCX 或 UTF-8 TXT。插件在本地提取文字，仅把文字发送到当前 API 服务商，不上传原文件，也不将它加入 Zotero 文献库。每份文件最多 20 MB；PDF 读取前 20 页；每份最多取 10,000 字符，总计最多 40,000 字符。发生截断时会提示。扫描版 PDF 需要先进行 OCR，加密或无可提取文字的文件无法用于推断。推断会单独调用一次模型，可能产生费用。中文结果先进入可编辑预览；应用前不会更改已保存的 Research Context。之后生成笔记使用已保存的内容。

**导入文献后自动生成粗读笔记** 默认关闭。开启后，每个新加入的文献条目都会调用一次你配置的 API，可能产生费用。

模板是提供给模型的格式要求，插件不会解析 `{{...}}` 之类的占位符。模型可能不完全遵循格式，请检查生成结果。

## 生成粗读笔记

1. 回到 Zotero 文献库，选中**一篇普通文献条目**，不要选 PDF 附件或已有笔记。
2. 右键选择 **快速添加粗读笔记**。
3. 等待状态提示从「正在生成粗读笔记……」变为「粗读笔记已生成」。
4. 展开原文献条目，查看新建的子笔记。Cards 模式把一级标题变成信息卡片；Classic 模式保留普通 Markdown 富文本样式；Flow & Tables 模式用蓝灰色步骤块、箭头和表格展示适合图解的内容。标题、列表、表格、代码块、粗体和斜体继续按 Markdown 转换。

卡片、流程和表格的排版只在本机进行，不会增加 AI 请求。模板仍然只需填写 Markdown，不需要 HTML。Flow & Tables 会在生成提示中引导模型按文献内容选择图解，不会强制每章使用。流程块使用 `quickread-flow` Markdown 代码块：每行一个步骤，用 `|` 表示同一层的并列分支；首版支持线性流程和一层并列分支。若增强渲染发生错误，插件会自动使用 Classic 样式完成笔记。Zotero 编辑器可能移除部分背景或圆角样式，但步骤、箭头和原生表格仍可编辑。

有 PDF 时，插件使用 Zotero 提取或索引出的 PDF 文本。没有 PDF 时，插件显示摘要模式提示，并用元数据和摘要生成笔记；若连摘要也没有，模型只能依据元数据。右键操作一次仅支持一篇文献；若有多个 PDF，使用第一个。

开启自动生成后，插件会监听新加入的文献条目（包括导入、Connector 和同步带来的新增条目），短暂等待 PDF 附件，然后按当前设置生成子笔记。若等待后仍没有 PDF，会使用摘要模式。已有条目不会补做；同一条目若已有本插件生成的子笔记，不会再次自动生成。批量导入会限量排队；关闭选项后，后续新增条目不再自动处理。右键手动生成仍可使用。

## 常见问题与限制

- **提示 API Key 或 Model 未配置：** 检查设置，填写对应字段并离开输入框以保存。
- **API 请求失败：** 使用“测试连接”查看 HTTP 状态与服务商消息。404 通常先检查 API 地址是否正确，401/403 检查密钥和模型权限。请求超时为 120 秒。
- **PDF 文本读取失败：** 确认 PDF 文件在本机可用。扫描件或无文本层的 PDF 可能无法被 Zotero 提取；插件不做 OCR。
- **笔记缺少论文后半部分：** 目前最多发送 PDF 前 80,000 个字符，超长时会告知模型已截断。较小上下文的模型仍可能无法处理全部输入。
- **模型返回为空或格式不对：** 检查所选协议与服务商是否匹配，以及模型是否支持文本响应；必要时调整 Analysis Prompt 与模板。

模型生成的事实和引用仍需人工核对。插件只适用于 Zotero 10，安装包目前通过手动下载和安装更新。
